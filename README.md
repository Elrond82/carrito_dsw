# Circuito

Tienda online de tecnología para Desarrollo de Sistemas Web. Los productos se cargan desde [Fake Store API](https://fakestoreapi.com/products) y el carrito queda guardado en el navegador.

## Qué incluye

- Catálogo con `fetch`, tarjetas de imagen, título y precio, y búsqueda.
- Carrito con cantidades, total y envío. Se guarda en `localStorage`.
- Página de contacto con validación.

## Cómo verlo

No hace falta instalar nada. Con un servidor local:

```bash
python -m http.server 5507
```

Después abrir `http://127.0.0.1:5507`.
